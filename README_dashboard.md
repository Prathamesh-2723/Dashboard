# Explainable AI for Network Security & Threat Investigation
## Final-Year Capstone Interactive SOC Dashboard

A complete, production-grade, offline-first Security Operations Center (SOC) dashboard built to showcase the final results of the capstone project: **"Explainable AI for Network Security & Threat Investigation: Distinguishing Human, Bot, and Autonomous AI Browsing Agents from Passive PCAP Flow Dynamics."**

---

## 🛡️ Project Overview & Architecture

The system passively analyzes network packet captures (`.pcap`), partitions traffic into **30-second non-overlapping temporal windows**, extracts **34 behavioral flow features** (nfstream-style flow statistics), and classifies traffic into three distinct behavioral classes:
1. **HUMAN** (`#2ECC71` Emerald Green): Organic human web navigation with high concurrency, irregular cognitive pauses, and rich media downloads.
2. **BOT** (`#F5A623` Industrial Amber): Classical scripted automation (e.g. Python requests/urllib, curl) with deterministic intervals and sequential single-threaded flows.
3. **AI-AGENT** (`#8B5CF6` Cyber Violet): Autonomous LLM-driven browsing agents (e.g. Playwright/Puppeteer driven by Claude/GPT) characterized by bursty DOM query actions interleaved with multi-second LLM reasoning delays.

Each verdict is explained using exact polynomial **TreeSHAP** attributions, translated into plain-English behavioral diagnostics, paired with actionable **counterfactual recourse scenarios**, and cross-referenced with **MITRE ATT&CK techniques** via an offline **RAG assistant**.

## 🔬 Swapping Real Data & Models (`USE_MOCK = False`)

All data access throughout the entire dashboard is centralized in `data_layer.py`. To plug in your real trained models and collected PCAP features:

1. Open `data_layer.py`.
2. Change line 22:
   ```python
   USE_MOCK = False
   ```
3. Place your real project artifacts in the respective folders:
   - `data/processed/dataset.csv`: Real 34-feature CSV generated by nfstream.
   - `models/classifier.pkl`: Serialized trained LightGBM classifier (`joblib.dump`).
   - `models/shap_explainer.pkl`: TreeSHAP explainer model.
   - `data/knowledge_base/mitre_attack_rules.json`: Local JSON index of MITRE ATT&CK techniques.

Every function in `data_layer.py` contains an explicit integration comment documenting the exact schema and loading hook. **Zero UI code changes are needed.**

## 🎯 Project Guide Presentation Script

When demonstrating this system to your academic project guide or examination committee:
1. **Start on Page 1 (Command Center):** Highlight the balanced 60-session tripartite dataset, the low CPU inference latency (4.2 ms), and point out the flagged uncertain sessions requiring analyst review.
2. **Move to Page 3 (Session Investigation):** Demonstrate how temporal slicing into 30-second windows allows fine-grained forensic analysis of session transitions. Show the multi-class probability bars and compare the active window against class averages.
3. **Showcase Page 4 (Explainability):** Emphasize that the system does not merely state "AI-AGENT"; it generates plain-English diagnostic sentences based on exact TreeSHAP contributions and prescribes what features must change to flip to HUMAN.
4. **Engage with Page 5 (Ask the Analyst):** Click the suggested chips to show RAG grounding against MITRE ATT&CK (e.g. T1071.001) with automated empirical claim verification.
5. **Demonstrate Page 6 (Evasion Lab):** Show the guide that you investigated adversarial threats—demonstrating that while an adversary can inject delays to shift timing entropy, post-hoc explanations lose stability faster than the primary classification verdict.
6. **Conclude on Page 10 (About & Research):** Walk through the honest novelty statement and the four research gaps addressed by your thesis.
